# Reglas de Negocio - Creador Presup

- **Abono:** 50% del total inicial (`depositPercent = 50`).
- **Saldo:** El restante (Total inicial - Abono) + Mensualidad del primer mes (si aplica) + Hosting del primer mes (si aplica).
- **Plazo de entrega:** 8 días hábiles promedio (`deliveryBusinessDays = 8`).
- **Páginas extra:** Valor de $15.000 CLP cada una.
- **Suscripción y Hosting:** Solo aplican para el tipo de proyecto `construccion`. Si es `venta`, ambos valen 0 y se ignoran.
- **Hosting y Dominio NIC Chile:** El dominio siempre lo compra el cliente. El hosting cuesta $10.000 CLP mensuales extra (si se aloja en el servidor de Samuel Valenzuela).
