# Modelo de Negocio: Creador Presupuestos

## Propósito
La aplicación está diseñada para ser una herramienta interna y semi-externa de generación rápida de presupuestos web y simulaciones arquitectónicas de interfaces (esqueletos). Su principal beneficio radica en la automatización del cálculo financiero de los proyectos y en proveer un "simulador didáctico" visual, que ayude a los clientes a entender la estructura de las páginas que se les van a construir.

## Impacto
1. **Eficiencia en Cotizaciones:** Reduce el tiempo de armado de cotizaciones complejas a menos de 5 minutos mediante fórmulas estandarizadas de componentes y horas de trabajo.
2. **Claridad para el Cliente:** El editor de esqueleto proporciona al cliente una representación visual libre de diseño de qué elementos conforman su web (Hero, Navigation, Features, Footer). Esto alinea expectativas desde la fase inicial.
3. **Presentación Profesional:** La exportación 100% vectorial asegura que los documentos finales en PDF sean ligeros, profesionales y escalables.

## Evolución Futura
- **Integración de Pasarelas de Pago:** Permitir pagar el enganche o total desde el documento generado.
- **Seguimiento de Leads:** CRM interno para dar seguimiento a los presupuestos.
- **Sincronización Cloud:** Guardar el historial de documentos en base de datos en lugar de `localStorage`.
